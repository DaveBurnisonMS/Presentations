# Dave Burnison's Presentations
This repo contains PDFs of presentations that I have used recently. These PDFs have many links including demos on YouTube and resources that you can use to dive in to specific GitHub capabilities. Share these PDFs with your colleagues so they can watch the demos and dig into the resources to get up to speed quickly.

+ **BRK106 AI-powered workflows with GitHub and Azure DevOps - Microsoft Ignite 2025-11-18.pdf** - 2025-11-18 Modernize your DevOps strategy with Agentic DevOps by migrating your Azure Repos to GitHub while continuing to leverage the investments you’ve made in Azure Boards and Azure Pipelines. We’ll walk through real-world patterns for hybrid adoption, show how to integrate GitHub, Azure Boards and Azure Pipelines, and share best practices for enabling agent-based workflows with the MCP Servers for Azure DevOps. Watch the recording here: https://ignite.microsoft.com/en-US/sessions/BRK106?source=sessions (Co-presented with [Dan Hellem | LinkedIn](https://www.linkedin.com/in/danhellem/)
+ **Migrating to GitHub - Microsoft Ignite 2025.pdf** - 2025-11-19 In addition to the Ignite session with Dan Hellem on “AI-powered workflows with GitHub and Azure DevOps”, check out my other Ignite presentation - “Migrating to GitHub”. The PDF is  packed with links to resources to learn about migrating to GitHub and people who can help you with the process. Special thanks to [Mickey Gousset](https://www.linkedin.com/in/mickeygousset) and [Joshua Johanning](https://www.linkedin.com/in/joshua-johanning) for helping me prepare for this presentation.
+ **AI Updates from GitHub Universe 2025.pdf** - 2025-11-13 GitHub Product updates from **GitHub Universe '25** as presented to the **Seattle AICamp Meetup**. This presentation was focused on AI related updates.
